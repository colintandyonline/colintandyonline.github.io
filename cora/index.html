About this guide

Can I talk to Cora here?

This engineering tour is currently a scripted text guide. The existing corporate Cora experience is available separately. Engineering-specific model, voice and verified contact handoff are not yet enabled.

Does the guide access private systems?

No. The guide uses predefined public links and reviewed project descriptions. It has no access to private repositories, personal records or the Command Centre.
