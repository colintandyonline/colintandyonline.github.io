# CTDG Engineering visual standard

Approved baseline: 07cb7b02ff206b6a27701c94dff6d398345d2fa0, 26 November 2026.

Preserve the approved CTDG identity: logo, typography, deep navy, cyan, existing project palette, local Lucide icon sprite and consistent rounded panels. Do not invent a replacement identity. Extend the visual system rather than rebrand it.

The homepage introduction is the original Cora Engineering film, integrated into the hero without conventional player chrome. Request unmuted playback five seconds after load; retain accessible play, pause, restart and fullscreen controls and the browser-policy fallback. Never crop captions or force mute. Preserve the four icon-led navigation destinations and the existing enquiry and sponsorship routes.

Use page-specific observatory motion: arcs on the homepage, networks on portfolios, orbital motion on ecosystem and lab, telemetry-inspired lines on intelligence and roadmap, precision grid on docs, circuits on services/contact, halo on Cora. Decorative signals are not live telemetry. Fill genuinely unused grid space without obscuring content, changing data or creating misleading charts. Respect the global pause control and reduced-motion preference. Use local vector/CSS effects, not unnecessary third-party animation libraries.

Project accents come from scripts/portfolio-records.json: orange for CTDG Website and Interactive Demos; purple KayaCart; green Gandalf Mobile; blue Axiom Architect; teal DeepMind Resources; gold TrailTrade. Use meaningful category accents on capability cards, restrained to icons, borders and tags. Follow scripts/icon-standard.md; no generic bullet lists for primary feature navigation.

New pages must follow the shared header/footer, icon vocabulary, typography, spacing and motion system. Public-facing copy should explain useful capabilities, not internal development administration. Preserve evidence boundaries and existing central contact routes. Verify desktop/mobile, keyboard controls, reduced motion, filters and live production assets before release. Changes to these approved design decisions require explicit approval; routine improvements consistent with them can proceed.

The release checker protects official artwork, homepage film integration, key navigation and the shared motion hooks. Visual acceptance and performance profiling remain separate checks.
